Start the stack

One command pulls the images, starts 13 containers and waits until every endpoint answers. The animation runs twice as fast as real time, with the timings measured on this project.

Compose starts everything at once, only the edge router waits for the front-end. Go services answer about 3 s after they start, the three Java services (carts, orders, shipping) need about 20 s more, so wait-for-stack.mjs polls all seven endpoints before any test begins.

      On a phone, swipe the diagram sideways to see all services.
